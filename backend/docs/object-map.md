# Объекты для карты

`GET /api/objects/map?bbox=30,50,31,51` возвращает компактные пины по T5783.
Запрос использует действующую сессию и текущие права пользователя из БД.
Ответ имеет `Cache-Control: no-store`.

## Область и фильтры

Обязательный `bbox` содержит четыре числа: west,south,east,north в WGS84.
Долгота от -180 до 180, широта от -90 до 90. Западная граница меньше восточной,
южная меньше северной; точки на границе включаются. Пустые, нечисловые,
неограниченные, повторные и перевёрнутые значения дают 422 по полю bbox.
Для числовых значений допустимы до 32 значащих цифр и степень десяти от -32 до 32.
Области с пересечением антимеридиана не поддерживаются; отправьте два запроса.

Фильтры `status`, `managerId`, `regionId`, `objectType`, `q`, `createdFrom`,
`createdTo` имеют те же значения, проверки и SQL-предикаты, что [список](object-list.md).
Они применяются вместе с bbox до ограничения количества. Поиск адреса работает
только для объектов с полным доступом. Чужой регион даёт пустой ответ менеджеру;
провідному возвращает ограниченные пины без статуса.
`sort`, `direction`, `cursor`, `limit` относятся к пагинации списка и здесь дают 422.

## Видимость и ответ

Менеджер видит объекты назначенных регионов, статус получает только по своим объектам.
Провідний видит сеть: в явно назначенных регионах со статусом, вне их — без статуса.
Директор з розвитку, CEO и Адміністратор
видят всю сеть со статусом. Погодження договорів видит сеть с ограниченным составом,
без статуса, как в реестре. Неактивный или отсутствующий пользователь получает 403.
Объекты с выполняющимся физическим удалением не показываются.

```json
{
  "content": [
    {"id": "00000000-0000-0000-0000-000000000001", "name": "Приміщення",
     "entrance": {"longitude": 30.5, "latitude": 50.4}, "status": "FOUND"}
  ],
  "limit": 2000,
  "truncated": false
}
```

Пин содержит только id, название, координаты и разрешённый статус.
При ограниченном просмотре поле status отсутствует, а не равно null;
клиент показывает такой пин нейтральным цветом. Ответ не содержит адресов,
контактов, коммерческих условий, технических параметров или файлов.

Выборка упорядочена по UUID, ограничена 2001 строкой в БД; лишняя строка служит
признаком truncated. До 2000 объектов — truncated=false, больше — true.
При усечении клиент сообщает, что показаны не все объекты, и предлагает
приблизить карту либо уточнить фильтры. Продолжение через курсор не требуется.
При перемещении карты запрашивайте новый bbox и заменяйте набор пинов;
устаревшие ответы предыдущих областей клиент должен игнорировать.

Используется существующий индекс координат. Карта не загружает полные карточки
и не выполняет запрос для каждого пина. Тест ObjectMapPerformanceIT измеряет
полный HTTP-ответ с 2000 пинами на базе из 50000 объектов: три прогрева и
20 замеров по каждой роли, сочетанию фильтров и широкой области, p95 менее 1 с.
Измерения записываются в игнорируемый target/t5783-performance.json.
Проверка на стенде выполняется после слияния зависимых MR.
